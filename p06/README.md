Map лучше объекта для корзины, потому что ключи сохраняют свой тип.
WeakMap нужен для хранения и кеширования данных по объектам, например DOM-элементам. Когда объект больше нигде не используется, он может быть удалён сборщиком мусора вместе с записью в WeakMap.

state.items.push() не вызывает перерисовку, потому что Proxy отслеживает изменения самого объекта, а не содержимого вложенного массива.
